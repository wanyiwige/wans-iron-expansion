# Hazen 第二批法术重做：preview.6

这批重做剩余 31 个原版已注册法术，加上之前 7 个，原版 1.4.0.14 的 38 个注册法术清单已经覆盖。未把原档中仅有类文件、被注释掉或未注册的设想法术算进去。20 件护甲与此前武器仍保留。原模组全部内容（Boss、全部护甲、饰品、世界生成等）没有因此完成。

这是 Forge 1.20.1 的独立实现：先解析原 JAR 对应源码的定义和行为，再用当前铁魔法的施法、伤害、反制、再施放、粒子、动画和网络 API 实现；没有导入 NeoForge 代码或将旧移植库打入 JAR。源参数和校验值见 `hazen-secondary-spells.json`、`hazen-secondary-projectiles.json` 与 `secondary-asset-receipts.json`。

## 材料、开关与备份

继续沿用原来的学派符文、升级珠和铁魔法原生抄写／灌注入口。原定义禁止制作或掉落的法术继续遵守该限制。不是把所有稀有法术无条件加入生存战利品。未补原 17 种附魔的全套注册与获取流程；灼焰装备分支现按原装备标签判断，新增附魔体系仍属于后续内容。

配置 `config/wans-hazen-recreation-common.toml`：

```toml
[hazen]
extraSpells = true
disabledSpells = []
```

`extraSpells=false` 单独禁用本批 31 个法术及配套效果，保留此前七个法术、武器和护甲。`spells=false` 关闭全部 38 个法术；`enabled=false` 控制整个 Hazen 模块。单项例如 `disabledSpells=["hailstorm","ionic_slash"]`，使用原短 ID。重启后生效，保留注册和已存物品数据；禁用的本批投射物自动移除，对应效果清理属性加成。

修改前 1353 项文件备份在 `development-backups/before-hazen-spells-20261016-121200/before-spells.zip`，逐文件 SHA-256 验证。仅撤销本批源码：

```powershell
python tools/remove-hazen-spells.py
```

默认预览，显式 `--apply` 才执行；先核对文件哈希并再次备份，遇到手动修改就停止。保留原有武器、七个法术、五套护甲、配置、存档、正式 JAR 与审计记录。回退后重新构建，不会自动替换游戏文件。之前的护甲专用回退清单若发现后续法术批次修改了共享文件会拒绝执行，应按批次逆序回退。
