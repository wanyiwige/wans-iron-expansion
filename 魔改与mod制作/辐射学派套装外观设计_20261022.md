# 辐射学派套装外观设计

日期：2026-10-22。状态：外观提案，待用户修改与确认。

本轮仅记录设计，不制作贴图、模型、装备代码、配方或部署包。四件装备的属性、套装效果、获取方式另行设计。

## 总体方向：临界监护者套装（暂名）

以“穿戴小型反应堆的辐射法师”为主题。采用高领长衣、密封面罩、青绿色金属护板与可见的裂变核心，连接已经确定的机械辐射眼、辐射法典与裂变法杖。

远看先读出三个特征：包住头部下半圈的高领、胸口明亮的核心、向下展开的分叉衣摆。肩部和靴子有厚度，腰部收窄，整体仍保留施法者的身形。

机械结构集中在眼部、胸部核心座、前臂与靴口；布料负责躯干和衣摆的大色块。左肩带一块较宽的屏蔽板，右肩紧凑，形成轻微不对称。线缆贴着身体连接，避免散乱悬挂。

## 配色与材质

| 用途 | 颜色建议 | 分布与画法 |
| --- | --- | --- |
| 内衬、兜帽、衣摆 | 深靛蓝 `#15192E` | 主体约一半；以两到三档明暗交代折面 |
| 金属护板 | 深青绿 `#075A63` | 肩、前臂、胸框、胫甲；亮边呈青绿色 |
| 金属高光 | 青绿 `#22AD99` | 只画受光边与转折面，不把每一圈边缘描满 |
| 能量与仪表 | 翡翠绿 `#27CF62` | 核心外圈、镜片、少量导流窗口 |
| 核心亮部与标识 | 黄绿色 `#DFF65B` | 核心中央、胸口辐射标识、关键警示刻度 |
| 小型机械零件 | 暗钢灰 `#617480` | 紧固件、接头与铰链，少量出现 |

这是起始色板，后续绘图时与已认可的三件装备共同校色。能量采用饱和色块；即使没有动态光晕，也应能辨认绿色镜片与黄绿色核心。

## 四件装备

### 1. 临界观测兜盔

- **轮廓**：深靛蓝兜帽内嵌硬质头盔，顶部略平，两侧各有一条短护脊。后脑完整包覆，前下方与高领相接。
- **正面**：一块窄的横向绿色观察窗，中央以一格暗色隔开；窗下是有三道宽排气槽的青绿呼吸面罩。观察窗保持厚实色块，不画细碎数字。
- **侧面**：左太阳穴设置小型圆形机械目镜，呼应机械辐射眼；右侧仅有一个短接头。目镜嵌在壳体里，不向外伸成长筒。
- **背面**：兜帽布面中央有一条短金属脊，两侧留出大块深色布料，靠下有两格绿色状态窗。
- **重点**：头部的识别点是“横窗＋侧置目镜＋密封下颌”。黄绿色集中在目镜内环，避免整个头部发亮。

### 2. 裂变容纳法衣

- **轮廓**：高领包住后颈，两块短肩甲向外平伸一小段。胸部硬质装置压在长衣外，腰带收束，下方衣摆向两侧展开。
- **正面**：胸骨处嵌一枚小型裂变核心，用近方形的青绿框架夹住。黄绿中心外套深色隔离圈；框架下方留一个独立的辐射三叶标识。
- **胸腹关系**：核心位于上胸，腹部保留深靛蓝大色块，两条短导流槽从核心座向腰侧延伸。胸框、能量槽和标识之间保留暗色间隔。
- **肩与手臂**：左肩是一块宽屏蔽板，边缘有三个粗警示刻度；右肩使用两块较小叠板。前臂外侧有一块护甲和一条绿色能量窗，肘窝保持柔软布料。
- **背面**：肩胛之间是一只扁平的矩形反应堆背匣，中央有一条竖向绿色观察窗，两侧各两道宽散热槽。背匣底部连接腰带，轮廓贴背。
- **衣摆**：前方分开，露出裤腿；后方分成两片较长尾摆，末端有青绿包边。主要长度到膝部附近，侧面留活动开口。
- **重点**：胸口核心为全套最亮的位置；背面依靠背匣和长衣分叉形成第二组识别点。

### 3. 铅封护腿

- **轮廓**：深靛蓝裤腿，外侧带窄青绿护板。腰部两侧各有一块短裙甲，承接法衣衣摆。
- **腰部**：中央是一枚方形机械腰扣，扣上用三格绿色条块表示仪表；右腰固定一只扁平密封罐，左腰保留简洁连接扣。
- **膝部**：两块有台阶折面的青绿护膝，上沿亮、下沿暗。只在护膝外侧放一格小能量窗。
- **背面与内侧**：保留完整裤料明暗，补出腰带连接、膝窝和裤缝，不出现大块无设计的纯色背面。
- **重点**：腿部给胸部核心让出视觉重心，以连续的深色裤腿保持整套修长感。

### 4. 闭环踏靴

- **轮廓**：厚底、方头，靴口略宽，青绿胫甲覆盖正前方。脚踝有一圈深色密封带。
- **正面**：胫甲中部是一条短黄绿色竖窗；鞋头使用两档青绿表现坚硬折面。
- **侧面**：外踝设置一枚小方形连接盒，内部两格绿光；连接盒与靴口之间有短机械接缝。
- **背面与鞋底**：后跟有横向固定扣；鞋底采用三段宽防滑纹。底色为深靛蓝，落地时保持厚重感。
- **重点**：两只靴子静态形制一致，依靠小面积能量窗与上身呼应。

## 正面、侧面与背面的统一要求

- 正面视觉顺序为胸口核心、面罩观察窗、肩甲轮廓，最后才是腰腿细节。
- 侧面能看见核心框厚度、贴背背匣、肩板和靴底；这些部位使用明确方块折面。
- 背面有背匣、短状态窗、分叉尾摆与后跟扣，保持与正面相同的贴图完成度。
- 辐射三叶标识只在胸部放一枚主要图案。其余位置使用槽口、刻度与连接件，保证核心图案醒目。
- 机械眼、法典与法杖保持各自已认可的外观；套装从它们的色板、核心夹框和机械目镜中提取共同元素。

## 像素与后续制作约束

1. 先确定四件装备的正面、侧面、背面轮廓，再绘制各面的细节。
2. 穿戴贴图各面的单位面积像素密度一致；目镜、辐射标识和能量窗沿同一像素网格绘制。物品栏图标另按最终画布安排，不强行把整套穿戴贴图塞进 16×16。
3. 以粗轮廓、宽排气槽、整格亮边表达机械细节。符号必须在游戏缩小后仍能识别，禁止在主体网格内掺入半格细线。
4. 每种材质先控制在少量明暗档，避免噪点式做旧。布料用成片褶面，金属用短直亮边，核心用饱和色块。
5. 后续需要增加几何厚度的位置优先考虑胸框、肩板、背匣与靴口；折缝、螺栓、刻度优先由贴图承担。各面的细节应服务于同一个方块造型语言。
6. 静态贴图先保证核心、面罩和导流窗颜色足够明确；动态效果可另议低频亮度变化。本轮不确定动画或运行效果。

## 后续外观验收目标

- 手持裂变法杖、装备机械眼或法典时，能明显看出来自同一套设计。
- 缩小观看时仍能读出高领、胸口核心与分叉衣摆。
- 侧面和背面同样有完整材质、结构与接缝。
- 发亮区域互有暗色间隔，胸口核心始终最突出。
