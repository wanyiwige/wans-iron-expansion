# 辐射学派十法术：2026-10-22 重制资源

这一版为十个法术分别重画了图标和世界贴图。世界素材独立生成，不再从图标里抠取轮廓。十张图标均有完全不透明的黑色背景：原生 32×32，按最近邻放大到游戏资源要求的 64×64，每个源像素严格占 2×2。世界贴图为原生 32×32 四帧序列；临界拼图的单格使用 16×16 四状态贴图。

`preview-icons-native.png` 同时展示放大图、32 像素和 16 像素视图。`preview-vfx-native.png` 展示最终游戏资源中的四帧，棋盘格只是预览背景，不在 PNG 里。它们是资源预览，并非游戏内截图。

## 来源和导出

使用内置 image_gen 逐个生成十个图标、十种法术主体的动画/状态图集、共用的冲击动画和金属材料图集。提示词和来源路径在 `sources.json`。选用母稿副本在 `sources/`；原始生成文件也保留在 Codex 生成目录中。铅幕母稿里的软光未直接进入游戏：导出时只保留扫描条、角标和中心标志的硬色像素。

`export-assets.ps1` 做素材裁切、统一尺度、有限色盘量化、透明度阈值和最近邻缩放。四帧打包为竖向条带，渲染代码显式选择 UV 帧；不依赖实体贴图通常不会读取的动画 mcmeta。所有 PNG 都设置 `blur:false`、`clamp:true`。`make-previews.ps1` 可重新生成预览。

主体：`isotope` 头顶烙印；`neutron` 中子核；`field` 低矮地面格阵；`curtain` 透空扫描幕；`chain` 可分段重复的放电条；`film` 曝光底片；`cloud` 云室雾点；`wake` 蓝色波纹；`shell` 碎裂空壳；`matrix` 九宫格的空、充能、激活和破碎四状态；`impact` 共用短促冲击。`pixel.png` 是单色顶点着色用的 1×1 工具纹理。

## 铅幕材质

沿用上一版在 Blockbench 中完成的九件立体构件，未改动构件的坐标、尺寸或厚度。重画银白金属、铅板接缝、警示带和紧固件材质，重新分配 54 个面的 UV；所有面保持每模型单位四个纹理像素的密度。

旧包未将 `entity/toxic/lead_curtain_metal` 加入方块纹理图集。新的图集显式包含它，并保留全部旧来源。Minecraft 原生 SpriteResourceLoader 的对比检查从 `expected=11 discovered=10 missing=1` 变为 `expected=11 discovered=11 missing=0`。金属使用环境光并保留最低八级方块光，发光幕面使用独立透明贴图。模型的朝向、灯的位置和出现/收拢动画随幕面一致。

构建与机制记录见项目 `development-records/辐射学派十法术重制_20261022.md`。实际客户端、光影和多人效果仍需在重启后的游戏中确认。
