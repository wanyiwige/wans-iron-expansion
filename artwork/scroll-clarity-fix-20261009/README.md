# 星辉与旅行卷轴的导出清晰度修复

日期：2026-10-09。

先前使用 imagegen 生成的原画包含超过 32 格的实际像素设计，直接最近邻缩小为 32×32 时，路线点、星芒尖角、卷边阴影被采样丢失。最近邻不会自动把这些细节重新设计到 32 格内。用户报告在游戏中细节模糊，当前修复首先处理已确认的导出损失。

保留已经确认的配色和展开外形，直接从既有生成原画重新导出 64×64 RGBA 贴图，而不是放大已损坏的 32×32 图。绘制内容仍为 imagegen 原画，System.Drawing 只用于像素尺寸导出和诊断预览。

- `scroll_astral-64.png`：星辉学派。
- `scroll_traveller-64.png`：旅行学派。
- `comparison-48px.png`：两种贴图分别以 48×48 显示后的最近邻放大对照，左侧为旧 32，右侧为新 64；这不是游戏截图。
- `backup/`：替换前的本地资源和源码贴图，已核对 SHA-256。
- `manifest.json`：导出、替换与备份哈希记录。

扫描 `resourcepacks/` 与 `resources/` 的 ZIP 文件未发现这两个模型或贴图的同名覆盖。两张本地贴图及模组源码已更新；活动 JAR 尚未重建。游戏内可以 F3+T 重载本地 KubeJS 客户端资源，实际显示仍需在游戏中复核。未修改图形设置、法术逻辑或卷轴模型。
