# 1.0.16 磁极套装穿戴修复

实际穿戴模型改为 Blockbench v2 的 109 个方块和原始 128×128 图集。导入脚本 `tools/import_magnetic_armor.cjs` 保留每个方块的尺寸、位置、逐面 UV，并转换 Bedrock 顶底面的 UV 方向。独立的 v2 工程不变。

原先的手写全封闭头罩、厚实腿部方盒和 64×64 模型/64×32 贴图组合退出渲染。新模型保留 v2 的敞口兜帽、半面机械面罩、分片袍摆和完整双线圈背包。旧两张贴图保留为历史资源，装备不再引用它们。

沿用已安装的 GeckoLib 4.8.3 `GeoArmorRenderer`，四个物品提供 GeoItem 实例缓存。头、躯干、双臂、双腿和双靴使用标准装备骨骼，跟随原生人物姿势；护腿腰带独立跟随躯干，只在腿部装备槽显示。额外处理铁魔法 NPC 的逐身体部位渲染入口，防止腰带漏显。四件装备属性与四件套逻辑不变。

源码检查：109 个方块、9 个装备骨骼、全部逐面 UV 位于 128×128 图集内，纹理直接复制原文件；顶部和底部坐标按 Blockbench 导出的现有 NPC 资源核对。编译和 JAR 检查完成后部署，旧 JAR 移入 mods/.codex_backups。

尚需游戏内实测：单穿各件、混穿普通装备、全套、蹲下、行走、骑乘、细手臂皮肤和铁魔法 NPC 穿戴。静态验证不能代替游戏画面的动作与穿模检查。
