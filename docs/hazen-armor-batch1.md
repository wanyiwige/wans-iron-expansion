# Hazen 第一批护甲重做

新增五套，共 20 件：宇宙学者、辉光水晶、鹦鹉螺骑士、霜噬骑士、恐惧钢骑士。物品 ID 为 `alex_caves_spellsbook:hazen_<套装>_<部位>`，同时放入主创造页和 Hazen 装备页。原档两套学校护甲各有 AzureLib／GeckoLib 两份注册，本次复用相同原图和模型，合并为一个原生物品；20 件覆盖原版 28 个 ID，不意味着新增了 28 件物品。

模型、UV、像素贴图、图标、霜噬装备音效和剑术套装状态图标直接读取用户给定的 1.4.0.14 JAR，保留原像素文件。没有重新画图或套用相似模型。Forge 1.20.1 的渲染、材料、属性、配方和事件重新实现，不依赖移植的 HazentouveLib／Ace’s Spell Utils 类。

## 属性与机制

|套装|每件额外属性|护甲值：头／胸／腿／靴|
|---|---|---|
|宇宙学者|125 法力、10% 宇宙强度、5% 全法术强度|3／8／6／3|
|辉光水晶|125 法力、10% 辉光强度、5% 全法术强度|3／8／6／3|
|鹦鹉螺骑士|125 法力、10% 水系强度、5% 全法术强度|3／8／6／3|
|霜噬骑士|125 法力、15% 冰系强度、10% 全法术强度、10% 总攻击速度、1 攻击伤害|5／10／8／5|
|恐惧钢骑士|15% 总攻击速度、1.5 攻击伤害、2.5 生命|4／9／6／4|

霜噬的韧性为 4、击退抗性为 0.15；恐惧钢为 2 和 0.05。学派三套耐久系数 32，近战两套 64，均保持原件定义。所有五套均防火；修复材料分别沿用魔法布料、秘银织物和恐惧钢锭。

所有胸甲使用铁魔法原生的一格灌注容器，其他部位不开放灌注。学派三套原定义没有独立四件套触发技能，不额外捏造。近战两套每件提供冰霜噬咬亲和 +1，完整同套四件提供额外 15% 基础攻击速度的剑术套装状态；混搭不能触发。脱下或禁用后移除套装状态，修正原代码检测无关法师状态、卸甲后长时间残留的情况。

恐惧钢的 Malum 镰刀熟练度通过可选属性注册 ID 查找：存在 `malum:scythe_proficiency` 时按原值每件 +10%，不引入硬依赖。当前实例没有 Malum，此可选分支未作运行验收。

新增 20 份原护甲配方及 1 份近战符文配方。符文和需要的材料引用沿用原配方；原有精简版的神圣模具和禅金锭继续使用。锻造学派胸甲保留基础胸甲已有的灌注法术、名称和附魔，武器锻造仍安装成品规定的固定法术。生成脚本为 `tools/prepare_hazen_armor.py`。

## 开关与回退

`config/wans-hazen-recreation-common.toml` 新增：

```toml
[hazen]
armor = true
disabledArmorSets = []
```

`armor=false` 关闭五套护甲的创造页入口、属性、亲和、套装奖励及配方；`disabledArmorSets=["frostbite_knight"]` 关闭整套；`disabledItems=["frostbite_knight_helmet"]` 关闭单件。`weapons` 不影响护甲，原总开关 `enabled` 仍控制全部模块。修改后重启。注册 ID、已有物品与已灌注法术数据保留；禁用不主动删除这些存档数据，也不抹除既有铁魔法灌注。

修改前 720 项源码／资源已备份到 `development-backups/before-hazen-armor-20261016-115217/before-armor.zip`，逐文件 SHA-256 验证通过。可独立撤销护甲源码：

```powershell
python tools/remove-hazen-armor.py
```

默认只预览。显式加 `--apply` 才会执行；发现文件被手动改过就停止，执行前再做完整备份。仅撤销此护甲批次，保留之前的武器／法术模块、存档、配置和正式 JAR。源码回退后重新构建；已有整合包中的 JAR 不会自动改变。

## 验证与交付

新增三组原生服务端断言：20 件属性／耐久／灌注槽／修复材料；完整套装／混搭／卸甲／禁用／亲和；20 份配方加载与胸甲锻造保留灌注。与旧六组同步断言一起记录在 `development-records/hazen-recreation/armor-native-checks.log`。这些检查在真实 Forge 服务端世界中同步执行，不等同于完整排程 GameTest。完整 GameTest 的启动仍受本机 Iron’s Lib HTTP loopback 故障阻断。

最终构建包含 `reobfJar` 和 `mergeRoacwClasses`，Java 17 字节码检查通过。473 条原始资源复制回执逐项 SHA-256 一致。使用已安装的 GeckoLib 4.8.4 原生解析器成功烘焙 55 个模型（包括新五套）与 11 个动画；Minecraft 1.20.1 原生图集加载器发现全部 117 张物品贴图并成功解码，原版图集保留。以上资源检查不包含 GPU 渲染。构建时 ForgeGradle 的在线证书探测一度失败，使用已有缓存和仅作用于该进程的跳过探测参数完成离线构建，没有修改全局 Java、网络或缓存。

完整回退基线连同修改前图集保存在同目录 `before-armor-with-atlas.zip`（721 项），哈希另见 `atlas-baseline-sha256.json`；原先 720 项备份保持不变。独立护甲回退及整个 Hazen 模块移除工具的默认预览均已通过，没有实际执行移除。

用户已反馈此前 preview.4 的武器／法术验证没有太大问题；新护甲的穿戴外观、动作适配、GUI、联机仍需独立客户端验收。当前正式实例的 preview.4 未被替换，本批交付 preview.5 构建产物。最终构建、原资源哈希与包内验证见 `development-records/hazen-recreation/verification.json`。
