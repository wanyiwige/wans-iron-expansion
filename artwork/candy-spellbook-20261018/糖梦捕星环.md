# 糖梦捕星环

糖果学派的法术书功能载体，外观是一件捕星法器：糖霜弯月框架围着悬浮虹糖，下方垂着莓粉、奶油和薄荷色糖晶。使用按原版图标规格逐像素绘制的 16×16 透明贴图，关闭模糊采样，沿用原生 `item/generated` 物品渲染；没有制作立体模型或额外 3D 几何。

物品 ID：`alex_caves_spellsbook:candy_starcatcher`。中英文名称为“糖梦捕星环”／“Sugardream Starcatcher”。

## 功能与属性

- 使用 Iron's Spellbooks 原生 `SpellBook`、铭刻容器和法术书 Curios 槽位。
- 10 个可铭刻法术槽，初始为空，不赠送固定法术，也不锁死其它学派的铭刻。
- 装备在法术书槽位时：糖果法强 +15%、最大法力 +200、法力回复 +10%。
- 稀有品质，不可堆叠，沿用本体同类法术书的防火属性。
- 原生法术书饰品渲染器显示这张像素贴图，主创造栏中可直接取得。

属性采用本体 `withSpellbookAttributes` 接口，只在对应槽位生效。百分比使用 `MULTIPLY_BASE`、最大法力使用 `ADDITION`。以常规本体学派法术书为数值参考，偏向糖果持续施法，没有加入自动施法、额外伤害触发或免费高级法术。

## 合成

```
魔法布  糖       魔法布
糖果符文 书      糖果符文
魔法布  稀有墨水 魔法布
```

合计：4 魔法布、2 糖果符文、1 糖、1 普通书、1 稀有墨水。使用普通书作为材料，避免消耗已经铭刻过法术的法术书。持有糖果符文时解锁配方。
