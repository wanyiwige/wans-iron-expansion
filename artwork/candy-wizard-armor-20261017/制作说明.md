# 糖果学派：糖霜巫师套装

本次完成巫师帽、法袍、长裤、靴子四件装备，以深莓紫衣料、奶油糖霜滚边、薄荷色包纸和焦糖鞋底统一外观。帽子采用宽帽檐和弯折尖顶，配糖果帽扣与悬挂糖饰；胸前有糖果领扣，腰侧带糖浆瓶、糖袋和糖果吊链。

## 像素贴图修订

先完成 Blockbench 几何，再绘制贴图。根据反馈移除了整片衣料等距重复的竖条纹，改为局部、不等距的褶皱明暗块面。随后把表面像素密度从每模型单位约 1 像素提高到约 2 像素；这是重新绘制并调整每面 UV，而非把旧图放大。

最终图集为 512×256，用于分别容纳 77 个立方体的 462 个面，保留透明空白和岛间间隔。糖果扣补充包纸折角和小块高光，玻璃瓶补出糖浆液面，袖口、衣领和下摆加入局部缝线与糖霜边缘。避免用密集条纹、均匀噪点或每面重复的符号填满衣料。没有使用平滑渐变和模糊采样。

## 游戏接入

四个物品 ID：`alex_caves_spellsbook:candy_wizard_hat`、`candy_wizard_robe`、`candy_wizard_leggings`、`candy_wizard_boots`。已加入主创造物品栏、物品图标、中英文名称和魔法布／糖果符文合成配方。使用 Iron's Spellbooks 原生护甲体系和 GeckoLib 护甲渲染，法袍沿用原生胸甲法术灌注初始化。

数值按现有法师装备基准制作，整套合计糖果法术强度 +20%、糖果法术抗性 +20%、最大法力 +200；没有新增持续粒子或被动触发效果。

## 验证

- Java 17／Gradle 8.8 离线构建及重混淆通过，产物版本 `1.2.1-candy-pixel-preview.12`。
- 使用实际 GeckoLib 4.8.4 的 JSON 解析和模型烘焙器验证，9 个护甲骨骼、77 个立方体通过，左右手臂及腿部枢轴正确。
- 462 个面的 UV 均在图集内且覆盖不透明像素，Blockbench 内嵌贴图与运行资源一致；3 个预览人偶方块没有导出到装备。
- 与 preview.11 对照，没有删除既有 JAR 条目；已有条目仅改变版本元数据、两项注册类和两份语言文件。旧法术、符文和升级法球资源保持一致。
- 正面、背面和静态摆腿姿态在 Blockbench 查看。姿态图是建模贴合检查，不代表游戏内动作验收。

构建及模型检查通过不等于游戏实测。尚未替换实例 `mods` 中的活动 JAR，也未进行游戏内第一／第三人称、跑跳、蹲伏、护甲组合和多人渲染验收。
