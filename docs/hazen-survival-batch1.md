## 开关与回退

新包首次加载时，Forge 会在 `config/wans-hazen-recreation-common.toml` 的 `[hazen]` 自动补全默认值：

```toml
survival = true
survivalWorldgen = true
survivalLoot = true
survivalProgress = true
```

`survival=false` 关闭本批新增生成、掉落、智木配方和自动解锁；子开关分别控制生成、掉落、解锁，重启生效。注册 ID、已有方块、玩家物品和已经解锁的配方保留。此前武器、护甲、法术继续使用原开关；`disabledItems` 同时约束本批追加的新武器掉落。本次未修改正式实例配置。

制作前逐文件哈希验证的源码快照：`development-backups/before-hazen-survival-20261016-172518/before-survival.zip`。归档哈希在 `development-records/hazen-recreation/survival-map.json`。

`python tools/remove-hazen-survival.py` 默认预览；加 `--apply` 时先备份现状，再恢复 preview.7 共享文件、移除本批源码/数据。哈希改变会拒绝覆盖手改。保留正式 JAR、配置、存档和审计记录；回退后重新构建。跨批次回退顺序为生存→法术→护甲。全模块移除工具已补齐共享标签和掉落表的精确清理。

- 丛生骸骨的原始来源是 1.21 沼骸，1.20.1 没有该生物，未擅自替换掉落对象。
- 原包没有配方或掉落入口的装备仍列为缺口，没有编造廉价替代配方。
- 未制作的饰品、火花礼服、蜘蛛毒牙、焦黑骨和附魔池列入 `survival-map.json` 的 `deferred`，不会引用无效注册 ID。
