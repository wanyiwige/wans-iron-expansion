# 糖果学派素材复用说明

用户约定：后续法术可以复用本批素材。大部分法术优先使用像素贴图和动画，已有模型仅在确需立体表现时复用。

资源命名空间为 `alex_caves_spellsbook`，效果贴图位于 `textures/entity/candy/pixel/`，模型位于 `models/candy/`。

| 素材 | 可复用内容 |
|---|---|
| `rainbow_rose/orange/lemon/green/blue/purple.png` | 六种配色图集，顶部为高光硬糖，薄荷所在区域也有对应彩色螺纹，奶白底色保留 |
| `candy_atlas.png` | 夹心糖、糖晶裂面、爆糖裂纹及基础糖果材质 |
| `trail.png` | 像素短尾迹，可调颜色、长度和宽度 |
| `crumb.png` | 糖屑、冰晶等小碎片，通过运行时着色区分 |
| `spark.png` | 施法亮点、反光和引信提示 |
| `turn.png` | 转折、锁定或快速改变方向的短提示 |
| `burst_0.png` 至 `burst_3.png` | 四帧爆闪，可调颜色、尺寸和播放速度 |
| `smoke.png` | 短烟与柔化爆发边缘，通过运行时透明度消散 |
| `rainbow_hard_candy_*.json` | 六色硬糖，复用同一正方体几何；使用前先判断贴图是否足够 |
| `peppermint_guard_*.json` | 六色厚薄荷盘，复用同一阶梯几何；可用于确需立体的薄荷旋转表现 |

当前绑定（preview.4）：七彩跳弹每次三颗糖、薄荷卫环和追刃每次五枚、薄荷滚轮每次三枚均从本次施法打乱的六色列表取色，同批不重复。服务器在生成时选择并同步 `PixelPalette`，生成后不逐帧随机换色。

后续复用先改变组合与时间节奏，必要时补专属贴图。不能因为存在现成模型，就默认后续所有弹丸必须使用模型。
