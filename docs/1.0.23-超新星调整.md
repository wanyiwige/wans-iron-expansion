# 超新星 1.0.23

## 生成位置与发射

- 2–5 个反应堆在施法者身后 2 格的竖直平面上等角排列，圆环半径 1.6 格。
- 圆心高度为施法者碰撞箱半高 + 1.6 格，确保最低一颗的生成坐标高于脚部。
- 只有 1 个时放在圆心；多个时不再在玩家面前横向并排。
- 身后位置按施法者水平朝向确定，上下瞄准不会把圆环转到前方或地面。
- 生成后全部沿施法时的视线方向发射，速度仍为原来的 0.75；继续使用原 Brutality 实体的追踪、碰撞、爆炸、音效和状态效果。

## 伤害

- 超新星生成的实体带持久化标记 alex_caves_spellsbook:supernova_reactor。
- SupernovaDirectDamageMixin 对标记实体的 getDamageMultiplier() 返回值乘以 100，让原来的攻击力直接命中伤害乘以 100。
- SupernovaExplosionDamageMixin 在原 BiomechReactor.onHit 的 LivingEntity.hurt 调用处对伤害参数乘以 100。
- 当前 Brutality 配置的爆炸基础伤害为 30；本法术反应堆传入的爆炸基础伤害为 3000。
- 未改动 Brutality 全局配置；无超新星标记的普通反应堆维持原伤害。Miracle Blight 的等级、持续时间维持原样。
- 这里的倍率指伤害调用前的基础值；游戏内实际扣血仍受原模组、护甲、抗性和受伤间隔等规则影响。
