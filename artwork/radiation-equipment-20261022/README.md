# 辐射学派装备外观第一稿

日期：2026-10-22。范围：设计与二维像素外观图，不包含建模、物品注册、属性实现、构建或部署。

## 裂变法杖

文件：`fission-staff-concept-v1.png`，透明背景。

用铅银色的开口钳架保护荧绿色裂变核心；钳架下方放一块黑底黄字色的核废料警示牌，牌上只有一个辐射标识。长杆以石墨黑色为主，握持段有深灰缠绕纹，黄色金属箍连接握把、杖颈和杖尾。绿色集中在核心与两处小型能量窗。

外观重点是“封装并约束裂变核心”，核心和金属钳架有明确的前后与连接关系。后续若建模，应做有实际厚度的钳架、核心和握柄，不能直接把整张正面图作为薄片模型。

## 铅封法典

文件：`leadbound-grimoire-concept-v1.png`，透明背景。

黑色封皮、大块黄色辐射徽记、铅银色护角与锁扣，书脊有两段绿色能量窗，页缝露出少量荧绿色。保留灰米色书页，让它在背包和手持状态下都能清楚地读作一本法术书。

标识在封面占据较大面积，不再依赖小字或细线。黄色封带与法杖上的黄色警示牌呼应；护角和法杖钳架共用金属色阶。

## 后续使用边界

两张 PNG 是本轮外观设计稿，生成图尺寸见 `image-checks.json`。它们还不是最终原生尺寸的 Minecraft 物品贴图，也不是可直接贴到模型上的 UV 图集；缩小显示与逐像素定稿留到外观确定之后。不得声称已完成游戏内视觉验收。

模型阶段应先确认完整体积，再为正面、背面、侧壁、端盖分别安排相同像素密度的纹理。装备属性、配方、等级与技能联动本轮均不定案。

`references/` 中的原模组资源仅供本地风格比对，不属于原创交付或发行资源。
