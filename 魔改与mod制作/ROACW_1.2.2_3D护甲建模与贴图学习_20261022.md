## 最值得参考的三套

### Plaguebringer：辐射套装的主要结构参考

它的面罩没有停留在一个立方头壳上：`mask` 向前倾斜 12.5°，左右面罩分别向两边转 22.5°；下颌、两侧护片和目镜继续分组，形成中央突出、两侧收拢的轮廓。

胸部使用 `chestplateFront` 的 12.5° 前后倾斜，再让左右胸片各转 22.5°。核心嵌在这些胸片之间，胸甲的体积先由几何成立。后方的 `canisterLeft/Right`、翼状外壳和肩部的两段护片形成有层次的背影。

128×128 基础贴图只使用 18 种不透明颜色。金属包边、暗槽、束带和小亮点按具体零件的 UV 绘制，颜色边界与结构边界对应。相同尺寸和 UV 的立方体有大量复用，主要说明它对重复部件有一致安排，而非给每个面随机截取一块材质。

辐射套装可以学习其倾斜面罩、胸口容纳结构、背罐连接及肩甲分层；保留我们自己的兜领、分叉衣摆、裂变核心与青绿配色，不直接照搬昆虫式外观。

### Mars：机械分组与转折关系

面罩左右分组、下颌、天线、胸甲、核心、后背喷口和靴子都参与轮廓。`chestplateRotate` 倾斜 12.5°，两侧背部连接片分别转 32.5°，部分部件继续通过 15°、22.5°、45° 等旋转形成转折。

值得学习的是零件之间的连接：主体、连接座、外壳、开口各自有位置和朝向，前后看均有完整设计。它的复杂度来自这些关系，不能仅用“多放一些小方块”替代。

辐射套装可以借鉴胸框向身体收拢的方式、肩甲的外扩角度、背匣和腰部的连接。Mars 的大喷口与天线并非辐射套装当前需要的部件。

## 对贴图画法的结论

1. **画布尺寸与像素密度分开决定。** 这八份模型的立方体 UV 均采用 box UV。通常一模型单位对应一纹理像素：例如 Plaguebringer 的基础躯干尺寸为 8×12×4，正面名义上对应 8×12 像素；其 inflate 会让实际表面略微外扩。128 或 256 画布主要容纳不同零件的 UV，并不意味着每个面都要画得非常细。
2. **纹理边界对应实际零件。** 包边贴着板甲边缘，暗色沿凹槽和内侧排列，高光以一格或少量整格表达。这里的效果不能只靠一张通用金属图裁成许多块来获得。
3. **颜色少，但明暗用途明确。** 深色用来分开相邻部件，亮色用于折边与关键受光面。主要材质的大色块保持完整，避免把磨损画成满面的随机噪点。
4. **透明与发光各有职责。** 六张基础贴图的 alpha 仅出现 0 和 255。每套还包含独立 glowmask；已额外核对 Plaguebringer 与 Mars 的渲染层，确实引用对应遮罩并使用 15728880 的全亮光照值。发光应由镜片、灯点和核心等局部承担。
5. **正背面共同完成。** 后脑、背匣、后腰、靴后跟和连接部件均有绘制。模型原生资源中也有少量零厚度立方体，但各套的护甲主体均由有厚度的结构构成。

## 与当前辐射试作的差距

辐射试作共有 169 个立方体、13 个分组，但主要造型依靠平直盒体与薄片叠放；旋转仅集中在衣摆。与这些参考相比，面罩、肩甲、胸框的转折不足，细小边条较多，主体体积关系偏弱。

第一版像素试贴使用了绘制材质库，再为各面裁取像素片段。它验证了配色和固定像素密度，但缺少按零件逐面安排的包边、暗槽、接缝与装配痕迹，因此尚不能达到参考套装的完成度。

后续辐射套装应按以下次序调整：

1. **先修裸模。** 面罩收成中央凸出、两侧斜收的结构；胸甲左右向核心容纳座转折；肩甲使用有厚度、分段外扩的护片；背匣补清连接关系；衣领与衣摆形成宽折面。
2. **确认主轮廓再处理小结构。** 模型数量不作为质量目标。将不影响轮廓的细边、刻度和螺栓交给贴图，保留需要真实厚度的核心座、肩板、目镜和背匣。
3. **重新安排 UV。** 以参考的粗像素尺度为起点，区分画布大小与单位面积像素密度，镜片、标识、布料和金属使用一致网格。对称重复件可以有计划地复用 UV。
4. **按零件逐面绘制。** 先画主色与折面，再画包边、内侧阴影和少量磨损；胸前辐射标识保持粗像素三叶形。原有深靛蓝、青绿与黄绿色方向保留。
5. **最后安排局部发光。** 镜片、裂变核心、状态窗可以进入独立遮罩，金属主体保持清楚的明暗层次。
